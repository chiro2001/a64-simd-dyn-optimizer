# interp8-vss 8 形状 20k 差分门禁（2026-08-17）

## 方法

- 候选：`kernels/interp8-vss-*/candidates/best_sve2.cpp`（提升自
  experiments/m30-interp8-vss-search 的 generic vertical-ss 发射器
  产物，gen_sve2_emit.py）；
- 参考：x265 `interp_vert_ss_neon<8,W,H>`（build/x265-8-clang-sve/
  libx265.a）；指针语义一致（都按“src 指向输出第 0 行、内部回退
  3 行”处理）；
- 协议：随机输入，契约范围 [-255,255]，strides {16,32,64}，
  coeffIdx {1,2,3}，每形状 20000 例，QEMU sve-max-vq=2。

## 结果（8 形状全部 0 失配）

| 形状 | 门禁 | fused_uop |
| --- | --- | ---: |
| vss-8x8 / 8x16 / 8x4 | 0 失配 | 142 / 254 / 90 |
| vss-16x16 / 16x32 / 16x4 | 0 失配 | 466 / 898 / 148 |
| vss-32x16 / 32x32 | 0 失配 | 1061 / 2062 |

## 边界说明

±30000 全幅输入下与 NEON asm 参考失配（~1.5-7% 位置）：根因是参考
asm 折叠形式（phase-2 先做 s0+s7 等 int16 加法）在契约外幅值下
int16 溢出，候选（svmla 全 8-tap int32 累加）不溢出——候选在契约
内正确且更稳；x265 实际数据路径范围远小于此，不影响生产。

## 结论

1. interp8-vss 8 形状在 x265 契约范围内全部 upstream-exact（20k
   × 3ci × 3st，0 失配），与 m30 搜索 verify 记录一致；
2. vss 家族门禁闭环（vsp 4/4、hps 6/8 + 2 契约限定、vss 8/8）；
3. 候选为 generic vertical-ss 发射器产物，fused_uop 142-2062。
