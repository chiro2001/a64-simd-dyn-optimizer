# 920B 真实视频端到端测试（2026-08-15）

## 输入

- 源视频：`1416529-hd_1920_1080_30fps.mp4`（367 帧，12.23s）
- 测试切片：本地 ffmpeg 转前 30 帧 raw YUV420（89MB），scp 到 920B 云端
  `/tmp/real_1080p_30f.yuv`

## 命令

```sh
taskset -c 0 build/x265-8-gcc/x265 --input /tmp/real_1080p_30f.yuv \
  --input-res 1920x1080 --fps 30 --frames 30 -o /dev/null \
  --pools 0 --frame-threads 1 --no-wpp --lookahead-threads 0 --b-adapt 0
```

## 结果（各 3 次）

| 配置 | run1 | run2 | run3 | 中位 |
| --- | ---: | ---: | ---: | ---: |
| 基线（未注入） | 8107 ms | 8129 ms | 8134 ms | 8129 ms |
| 注入 79 个 SVE1 kernel | 8990 ms | 8983 ms | 8969 ms | 8983 ms |

当前注入相对基线 **+10.5% 变慢**，与 640x360 随机 YUV 的 +4.5% 方向一致。
