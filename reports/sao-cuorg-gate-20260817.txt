# SAO 重建 kernel（saoCuOrg E0/E1/E1_2rows/E2/E3/B0）20k 门禁

## 方法

- 候选：`kernels/sao/seed_*.cpp`（NEON ACLE，docs/45 语义）提升至
  `kernels/sao/candidates/best_*.cpp`（E0 符号对齐 manifest
  dynopt_sao_e0_64_sve2）；
- 参考：x265 C 语义（third_party/x265/source/common/loopfilter.cpp
  processSaoCUE0/1/1_2Rows/2/3 + processSaoCUB0），门禁内直接移植
  （NEON asm 参考为匿名命名空间不可链接）；
- 协议：随机输入，值域 [0,255]，strides {64,65,96,128}，
  offset ∈ [-31,31]，每 kernel 20000 例，QEMU sve-max-vq=2；
  E0/E1/E2/E3 额外随机 sign/upBuff ∈ {-1,0,1}。

## 结果（全部 0 失配）

| kernel | 形状 | fused_uop |
| --- | --- | ---: |
| saoCuOrgE0 | 64x2 | 269 |
| saoCuOrgE1 | 64x4 | 517 |
| saoCuOrgE1_2Rows | 64x2 | 261 |
| saoCuOrgE2 | 64 | 133 |
| saoCuOrgE3 | 64 | 117 |
| saoCuOrgB0 | 64x4 | 219 |

## 结论

1. SAO 重建家族（edge offset E0-E3 + band offset B0）全部 upstream-
   exact（与 x265 C 语义 20k 差分 0 失配）——backlog “sao E1–E3
   重建 kernel（saoCuOrg*）”关闭；
2. 候选为 NEON ACLE 种子（固定 64 宽），后续可沿 docs/45 的
   tbl-u16 SVE2 布局生成 SVE2 版本再实测；
3. 门禁初跑 E1/E12/B0 失配为门禁参考未按 stride 前进行指针的
   harness bug（已修正），非候选问题。

## SVE2 版（2026-08-17 晚）

- `kernels/sao/candidates/best_sve2_e0.cpp`：saoCuOrgE0 的纯 SVE2
  实现。横向 sign 递推 sl_i = -sr_{i-1} 改写为 1-lag 差分：
  edge_i = 2 + sr_i - sr_{i-1}，用 `svindex`+`svinsr` 构造 TBL2
  移位向量 [-sl, sr_0, ..., sr_30]（lane0 来自 dup(-sl)），整条
  32B 并行处理；
- 进位用 `svlastb` 取最高活跃 lane（`svlasta` 语义是**首个**活跃
  lane，此前 8-lane 版用 `svdup_lane`+全真谓词绕开）；TBL2 索引
  用 GPR 常数 + `insr wzr`，无 NEON `movi`；
- clip 用 128 偏置 + 回绕 u8 加法（与 B0/E1 家族同）；
- 20k 差分（4 strides × 随机 offset/signLeft）**0 失配**；
  fused_uop=65（对比 NEON seed 版 269；此前 8-lane 版为 168，
  且 22 为误记——2026-08-17 复核修正）；
- 修正：offset 表原先用 `svld1_s8(svptrue_b8(), offs)` 从 16 字节
  局部数组读 32 字节（越界 UB，仅因 tbl 索引 0..4 未暴露），改为
  `svwhilelt_b8(0,16)` 谓词加载。

## SVE2 版 B0/E1（2026-08-17 晚，追加）

- `best_sve2_b0.cpp` / `best_sve2_e1.cpp`：B0（band offset，64x4）
  与 E1（vertical edge offset，64x4）纯 SVE2 候选；
- 关键优化：这两个 kernel 的 lane 之间**无横向递推**（E0 才有
  signLeft 逐 lane 递推），因此按整条 32 字节 Z 向量并行处理，不再
  按 8-lane 小块展开；
- clip(p + off) 用 128 偏置 + 回绕加法实现，免展开/收窄：
  `ps = p - 128`（s8 精确）→ `s = qadd_s8(ps, off)`（饱和到
  [-128,127]，恰为 clamp(p+off-128)）→ `out = u8(s) + 128`（普通
  u8 加法，模 256 精确等于 clamp(p+off,0,255)）；
- B0 的 `p >> 3` 用 SVE2 `LSR .B` 立即数（GCC arm_sve.h 无
  svlsr_n_u8，Clang 有；内联汇编发射，纯 Z 寄存器）；
- E1 的 edge ∈ [0,4]，offset 表用 `svwhilelt_b8(0,16)` 谓词加载
  16 字节（避免越界读取）；

| kernel | 形状 | fused_uop | NEON seed 对比 |
| --- | --- | ---: | ---: |
| saoCuOrgB0 SVE2 | 64x4 | 57 | 219（-74%） |
| saoCuOrgE1 SVE2 | 64x4 | 129 | 517（-75%） |

- 20k 差分（4 strides × 随机 offset/upBuff）**0 失配**（B0/E1 各
  20000 例，QEMU sve-max-vq=2）；
- DB 174 行（含 E0 修正行）；契约语料 128 行含 6 cuorg region，
  无需新增 region 契约。

## SVE2 版 E1_2Rows/E2/E3（2026-08-17 晚，追加）

- `best_sve2_e1_2rows.cpp` / `best_sve2_e2.cpp` / `best_sve2_e3.cpp`：
  与 E1/B0 相同的 32B 整块 + 128 偏置回绕 clip 模式；
- E2 的 bufft[x+1]、E3 的 upBuff1[x-1] 只是按 x±1 偏移存取，lane
  之间无递推，整块并行；E3 尾部 x=33..63 用 31-lane 谓词；
- 20k 差分（4 strides × 随机 offset/buff）**0 失配**；

| kernel | 形状 | fused_uop | NEON seed 对比 |
| --- | --- | ---: | ---: |
| saoCuOrgE1_2Rows SVE2 | 64x2 | 65 | 261（-75%） |
| saoCuOrgE2 SVE2 | 64 | 33 | 133（-75%） |
| saoCuOrgE3 SVE2 | 64 | 33 | 117（-72%） |

- **saoCuOrg 六个 kernel 的 SVE2 版全部闭环**（E0/E1/E1_2Rows/
  E2/E3/B0，QEMU vq=2 各 20k 0 失配）；DB 177 行。
- **纯 SVE 核验**：`check_isa_level --no-neon --level sve2` 六个
  kernel 全部 0 NEON 违规（E0 亦无 umov/D 寄存器存取；未知
  mnemonic 仅 catalog 缺 cmphi/sunpklo 等 SVE2 指令，非违规）。
