# 工具与脚本用法手册（2026-08-16）

给 agent 与开发者：所有命令行入口集中在此。稳定性标注：

- **stable**：长期使用、接口稳定、有回归保护；
- **beta**：2026-08-16 前后新增，接口可能调整，使用前先看源码头部；
- **experimental**：诊断/一次性工具，输出格式可能变。

## 1. 环境与覆盖

- `scripts/doctor.sh`（stable）：环境体检（编译器/QEMU/MCA/依赖）。
- `scripts/bootstrap.sh`（stable）：幂等安装缺失工具。
- `python3 tools/enumerate_x265_simd.py`（stable）：AArch64 dispatch
  覆盖清点（期望 29/29、todo=0）。

## 2. 搜索与生成（布局搜索 + 专用发射器）

- `python3 tools/search_sve2_layouts.py --kernel <k> --workers 4 \
  --outdir experiments/<dir> --mca-top 5 \
  --mca-bin /home/chiro/llvm-src/build-mca/bin/llvm-mca`（stable）
  - `--isa sve1`（920B）、`--isa sve2`（950）、`--isa neon`（纯
    NEON 搜索）；`--target 920B|950` 是 `--isa` + MCA profile 别名。
- `tools/gen_verify.py`（stable）：按 kernel manifest 生成 QEMU
  差分 verify 源。
- `tools/check_isa_level.py --object <candidate.o> --level sve2`
  （stable）：候选对象静态 ISA 门禁；`--no-neon` 追加纯 SVE 模式
  （任何 NEON v/d/q 寄存器指令都判违规，用于纯 SVE 发射验收）。
- `tools/extract_seed.py` / `tools/recover_loops.py`（experimental）：
  从上游提取/恢复种子，输出格式可能变。

## 3. IR 宽度无关管线（AGO 通用 lowering）

- `python3 tools/dag_pipeline.py --kernel <k> --func <sym> \
  --dag <module>:<fn> --emit <module>:<fn> \
  [--march armv8.2-a+dotprod] [--verify-flags "..."]`（**beta**）
  - 一站式：DAG → lane def-use → emit → 编译 → QEMU vq=1/2 差分 →
    动态 fused_uop 计数；新家族只需提供 DAG 构建器 + 发射器
    （docs/66 §4）。
- `optimizer/ir/lane_defuse.py`（**beta**）：lane 粒度 def-use 校验；
  新 op kind 必须补 `lane_semantics`，否则 defuse 报
  `lane semantics: kind ...`。
- `optimizer/ir/interp8_op_ir.py` / `interp8_emit.py`（**beta**）：
  interp8 hpp (W,H) 宽度无关 DAG/发射器（8/16/32/64 宽度）。
- `optimizer/ir/pure_sve_helpers.py`（**beta**）：纯 SVE 原语集
  （load/store/rev/tbl/sdot/rshrn/uzp/add 全为 sv* 或 z 寄存器内联
  汇编，`--no-neon` 下 0 违规；回归在
  `tools/test_pure_sve_helpers.py`）。
- `optimizer/ir/dct16_pure_sve_emit.py`（**beta**）：dct16 纯 SVE
  发射器（neon8 fused8 源码 → sv*/psv_* 替换层；VL=128 限定；
  0 NEON + 20k 差分 PASS + 与 neon8 数值一致，见
  `tools/test_dct16_pure_sve.py`）。
- `optimizer/ir/pure_sve_helpers.py` 的 `psv16_*`（**beta**）：16-lane
  全 VL 原语（load/store/rev/sdot/rshrn），QEMU VL=256 + 0 NEON +
  数值自检（16-lane 发射器地基）。
- `python3 tools/emit_interp8_ir_candidates.py [kernel...]`（**beta**）：
  为 interp8 hpp 各形状生成 `kernels/<shape>/candidates/best_ir.cpp`
  （`AGO_IR_FILTER=1` 注入选择用）。

## 3.5 AGO 自动搜索工具链（M3/M4，2026-08-18 起）

- `python3 tools/ago_auto_search.py --kernel <k> [--rank-by permute|ago]
  [--discover] [--verify] [--isa sve1|sve2|neon] [--march ...]`
  （**beta**）：AGO 自动搜索主入口——免 manifest 直接发射 cover 模板
  （`optimizer/ago/covers_*.py`），编译 + static_counts + 排序。
  - score = permute_ratio + fused_uop/1000 + cp_lat/500（cp_lat 项按
    950 仲裁校准，权重推导见 docs/83 §0 round-12）
  - `--discover`：枚举发射器/模板参数网格变体与精选同台排序
    （dct16 even-k 模式、dct32 batch 轴）
  - `--isa sve1`：920B 约束——SVE2-only intrinsics 编译失败打印
    **ISA REJECT** 并剔除，幸存者排序（satd-16 在 sve1 下自动选
    软件 cadd 版 best_sve1）
  - `--verify`：对最佳候选做 QEMU bit-exact 验证（interp8 已实现）
- `python3 tools/search_sve2_layouts.py --backend ago --kernel <k>
  --target 950 --rank-by ago --short-cases 2000`（**beta**）：全管线
  （manifest 驱动）——QEMU 差分门禁 + ago_pred（950 代价表预测）+
  校准（见下）。ago 后端计数为全对象 static_counts（薄 wrapper
  伪影防护）。
- `python3 tools/feedback_calibrate.py --ingest <measurements.json>
  [--table benchmarks/neon-timing-n1/timing-n1.json]
  [--out build/calibration.json]`（**beta**）：Feedback Loop——逐行
  发射 cover → 编译 → predict_from_features → scale =
  measured/predicted → 每 kernel 中位 scale 写校准文件；rank-by ago
  自动加载（或 $DYNOPT_CALIBRATION）乘上 ago_pred。build/ 已
  gitignore（校准文件不污染仓库）。
- `optimizer/ago/calibration.py`（**beta**）：load_calibration（缺失/
  坏 JSON → 空，永不抛错）、apply_calibration、fit_scales（中位 +
  [0.5,2.0] outlier 过滤）。
- `optimizer/ago/covers_*.py`（**beta**）：每 kernel 一个 cover 模板，
  协议 = `cover_meta()`（covers/names/cp_chains/tail_ops/
  expected_permute_ratio）+ `emit_cover(cover, func_name)`。
- `optimizer/templates/`（**beta**）：region-schedule 模板库
  （neon_bridge/svdot_s32_direct/loop_ksections/cadd_butterfly），
  `select_template(kernel_type, constraints)` 按预测 permute 选模板。
- **语料库状态（2026-08-20）**：自动搜索覆盖 **40 kernel / 13 家族**
  ——interp8 6 形状、sao 体系 9（stats 5 + 重建 4）、satd 13 形状、
  sa8d 4、dct 3、sad/psy-cost/cost-coeff；全部经 QEMU 门禁；
  docs/82 家族表为权威记录。

## 5. 注入

- `python3 tools/build_preload_so.py --isa <sve1|sve2|...> --vl 16|32 \
  --kernels k1,k2 --opt=-O3 \
  [--out build/xxx.so] [--inject-outdir build/xxx] \
  [--workdir build/xxx-work] [--json report.json]`（stable）
  - `--target 920B|950` 别名；`AGO_IR_DCT/PIXEL/SAO/ASM/FILTER=1`
    选 IR 生成候选，`AGO_NEON_DCT=1`/`AGO_IR_SVE1=1` 覆盖目标；
  - `AGO_PURE_SVE=1`：纯 SVE 模式，候选对象含任何 NEON v/d/q 寄存器
    指令即跳过（check_isa_level --no-neon）；
  - `--isa sve1 --vl 16`：920B/N1（NEON 优先）；`--isa sve2 --vl 16`：
    710；`--isa sve2 --vl 32`：950。
- `scripts/build-x265-injected.sh --isa <isa> --kernels <list> \
  --build-dir build/x265-8-... --inject-out build/dynopt-inject`
  （stable）：把候选编进 x265 静态库（非 LD_PRELOAD）。
