# 工具与脚本用法手册（2026-08-16）

给 agent 与开发者：所有命令行入口集中在此。稳定性标注：

- **stable**：长期使用、接口稳定、有回归保护；
- **beta**：2026-08-16 前后新增，接口可能调整，使用前先看源码头部；
- **experimental**：诊断/一次性工具，输出格式可能变。

## 1. 环境与覆盖

- `scripts/doctor.sh`（stable）：环境体检（编译器/QEMU/MCA/依赖）。
- `scripts/bootstrap.sh`（stable）：幂等安装缺失工具。
- `python3 tools/enumerate_x265_simd.py`（stable）：AArch64 dispatch
  覆盖清点（期望 29/29、todo=0）。

## 2. 搜索与生成（布局搜索 + 专用发射器）

- `python3 tools/search_sve2_layouts.py --kernel <k> --workers 4 \
  --outdir experiments/<dir> --mca-top 5 \
  --mca-bin /home/chiro/llvm-src/build-mca/bin/llvm-mca`（stable）
  - `--isa sve1`（920B）、`--isa sve2`（950）、`--isa neon`（纯
    NEON 搜索）；`--target 920B|950` 是 `--isa` + MCA profile 别名。
- `tools/gen_verify.py`（stable）：按 kernel manifest 生成 QEMU
  差分 verify 源。
- `tools/check_isa_level.py --object <candidate.o> --level sve2`
  （stable）：候选对象静态 ISA 门禁。
- `tools/extract_seed.py` / `tools/recover_loops.py`（experimental）：
  从上游提取/恢复种子，输出格式可能变。

## 3. IR 宽度无关管线（AGO 通用 lowering）

- `python3 tools/dag_pipeline.py --kernel <k> --func <sym> \
  --dag <module>:<fn> --emit <module>:<fn> \
  [--march armv8.2-a+dotprod] [--verify-flags "..."]`（**beta**）
  - 一站式：DAG → lane def-use → emit → 编译 → QEMU vq=1/2 差分 →
    动态 fused_uop 计数；新家族只需提供 DAG 构建器 + 发射器
    （docs/66 §4）。
- `optimizer/ir/lane_defuse.py`（**beta**）：lane 粒度 def-use 校验；
  新 op kind 必须补 `lane_semantics`，否则 defuse 报
  `lane semantics: kind ...`。
- `optimizer/ir/interp8_op_ir.py` / `interp8_emit.py`（**beta**）：
  interp8 hpp (W,H) 宽度无关 DAG/发射器（8/16/32/64 宽度）。

## 4. 验证与回归

- `python3 tools/test_gen_emit.py`（stable）：通用发射器冒烟回归。
- 差分门禁：`tools/test_*.py`（stable）+ `dag_pipeline`（beta）。
- 全套回归（代码改动提交前必须跑）：
  ```sh
  python3 -m unittest discover -s tools -p 'test_*.py'
  python3 -m unittest discover -s optimizer/ir
  python3 -m unittest discover -s optimizer/ago
  ```
- TestBenchLite：
  - `scripts/build-testbench-lite.sh <candidate.o> <libdir> \
    --gate <g> --seed <s>`（stable，QEMU VL=256）
  - `scripts/build-testbench-lite-native.sh <candidate.o> <libdir> \
    --gate <g> --seed <s>`（stable，目标机原生；内部等价
    `RUN_MODE=native CXX=g++`）。
- `scripts/paired_ci.py base_ms.txt opt_ms.txt`（stable）：paired
  bootstrap95；diff = base - opt，>0 候选更快。

## 5. 注入

- `python3 tools/build_preload_so.py --isa <sve1|sve2|...> --vl 16|32 \
  --kernels k1,k2 --opt=-O3 \
  [--out build/xxx.so] [--inject-outdir build/xxx] \
  [--workdir build/xxx-work] [--json report.json]`（stable）
  - `--target 920B|950` 别名；`AGO_IR_DCT/PIXEL/SAO/ASM/FILTER=1`
    选 IR 生成候选，`AGO_NEON_DCT=1`/`AGO_IR_SVE1=1` 覆盖目标；
  - `--isa sve1 --vl 16`：920B/N1（NEON 优先）；`--isa sve2 --vl 16`：
    710；`--isa sve2 --vl 32`：950。
- `scripts/build-x265-injected.sh --isa <isa> --kernels <list> \
  --build-dir build/x265-8-... --inject-out build/dynopt-inject`
  （stable）：把候选编进 x265 静态库（非 LD_PRELOAD）。

## 6. 实机测试与 E2E

- `scripts/quick-test-real-machine.sh <950|920b> [report]`（stable）：
  门禁 + paired CNTVCT 报告。
- `scripts/verify-preload-real-machine.sh <user@host> sve1`（stable）。
- `scripts/freeze-best9.sh|freeze-best9-n1.sh|freeze-best9-128.sh`
  （stable）：best9 冻结复现（30f 5+5 + md5 + paired CI）。
- `scripts/freeze-ablate.sh`（**beta**）：参数化 kernel 子集 A/B
  （`KERNELS=... FREEZE_FRAMES=30|100 FREEZE_INPUT=... FREEZE_MD5=auto`）。
- `scripts/freeze-four-arm-n1.sh [host] [rounds]`（**beta**）：多臂
  100f 交错 A/B（`ARMS=... SO_BEST9=... REPO=... TAG=... SKIP_MD5=1`）。
- `scripts/freeze-950-dct.sh <user@host>`（**beta**）：950 23-kernel
  一键 E2E（`GATE=1` 附加原生 TestBenchLite）。

## 8. 诊断（experimental）

- `python3 tools/trace_entropy_calls.py [outdir]`：生成 x265 熵族
  调用轨迹包装（DYNOPT_TRACE_PATH 录制）。
- `benchmarks/entropy_trace_replay.cpp`：真实轨迹拆分/逐桶回放计时
  与 verify 模式。
- `tools/parse_quick_report.py`：quick-test paired 结果回填/验收表
  （依赖报告格式，改动前先看源码）。
