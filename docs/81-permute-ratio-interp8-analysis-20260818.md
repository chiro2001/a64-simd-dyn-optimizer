# docs/81: permute_depth_ratio 跨 interp8 家族分析 (2026-08-18)

## 概述

将 `permute_depth_ratio` 预测器从 dct 家族推广到全部 interp8 变体
（hpp/vpp/hps/vps/vsp/vss），验证其作为 950 性能预测指标的普适性。

## 背景

P1 阶段发现 `permute_depth_ratio`（关键路径上 permute 指令占比）与
950 实测性能呈完美负相关（Spearman rho=-1.000）。dct16/dct32 已验证：
- op895 (18.5%) = 快（0.875 ratio）
- sve16 (48.1%) = 慢（3.49x slow）
- 阈值 <30% 为"快速区间"

P5 阶段将此预测器应用于 interp8 hpp，发现 best_sve2.cpp 高达 53.3%
（远超阈值），svdot_s32 候选降至 20.5%。本报告扩展到全部 interp8 变体。

## 优化优先级排序

基于 permute_ratio 分析，interp8 家族后续优化优先级：

1. **hpp 8x8（已完成）**：53.3% → 20.5%（svdot_s32 候选）
2. **vss 家族（次优先）**：15-20%，接近 dct32 opbase。但未超 30% 阈值，
   先观察 950 实测是否确实是瓶颈
3. **hpp 16x16/32x32（已完成）**：25-26%，已在安全区间
4. **其他家族（无需优化）**：0-9%，已充分优化

## 关键洞察

1. `permute_depth_ratio` 成功区分了"需要优化"和"已充分优化"的 kernel
2. interp8 hpp 8x8 是唯一超过 30% 阈值的，与 dct16 sve16 (48.1%) 同类
3. svdot_s32 方案（s8×s8→s32，8 pixel/lane）天然避开 addp RMW，
   是解决高 permute_ratio 的通用模式
4. vss 家族虽未超阈值，但 32x32 有 28 对 spill，可能是另一个瓶颈
5. 预测器在 interp8 家族中的表现与 dct 家族一致，验证了普适性
