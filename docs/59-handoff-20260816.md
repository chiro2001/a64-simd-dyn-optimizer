## 8. 常用命令

```sh
# 构建注入 bundle（.so 或 inject patch）
AGO_IR_PIXEL=1 AGO_IR_SAO=1 AGO_IR_ASM=1 AGO_IR_FILTER=1 \
python3 tools/build_preload_so.py --isa sve1 --vl 16 \
  --kernels satd-8,sa8d16,sao-stats-e0,sad,mc,ssd,interp8-16 \
  --opt=-O3 --out build/dynopt-ir-all.so --workdir build/ir-all-work

# 通用管线门禁（新家族接入只需 DAG+发射器）
python3 tools/dag_pipeline.py --kernel satd-8 \
  --func dynopt_satd_8x8_sve2 \
  --dag satd8_op_ir:satd8_dag --emit satd8_emit:emit_satd8 \
  [--march armv9.4-a+sve2p3]

# TestBenchLite（dct16/32）
scripts/build-testbench-lite.sh <cand.o> build/x265-8-testbench \
  --gate dct16 --seed 1

# E2E（每台机器）
taskset -c 0 ./x265 --input /tmp/real_1080p_30f.yuv \
  --input-res 1920x1080 --fps 30 --frames 30 \
  --pools 0 --frame-threads 1 --no-wpp --lookahead-threads 0 \
  --b-adapt 0 -o /tmp/out.mp4
LD_PRELOAD=/path/dynopt-ir-all.so ./x265 ...   # A/B
```

回归测试：`tools/test_*.py`（dct16/dct32/satd8/sao/asm/interp8/
lane_defuse）+ `optimizer/ir` 的 unittest（test_dot_ir 等）+ `ago`
discover。
