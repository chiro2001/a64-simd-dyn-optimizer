## 5. 950（SVE2）快速测试指南（待内网窗口）

前置：950 上干净 `build/x265-8-gcc`（SVE2 构建）、yuv、注入脚本。

```sh
# 1. 构建 950 注入 bundle（SVE2 目标）
python3 tools/build_preload_so.py --isa sve2 \
  --kernels cost-c1c2-flag,cost-coeff-nxn,cost-coeff-remain,sa8d16,\
satd-8,scan-pos-last,interp8-vps-8x8,interp8-vps-8x16,interp8-vps-16x16,\
interp8-vps-16x32,interp8-vps-32x16,interp8-vps-32x32 \
  --opt=-O3 --inject-outdir build/dynopt-inject-best8-950 \
  --workdir build/preload-work-best8-950 \
  --json build/dynopt-inject-best8-950/report.json

# 2. 推送 + 注入（沿用 cloud-e2e-inject.sh）
# 3. E2E：bash scripts/freeze-best8.sh <user@950>
#    注意：950 码流 md5 与 920B/N1 均不同，脚本已改为同机一致即 PASS
```

注意：SVE2 目标下 interp8-vps 候选仍为 NEON 指令（-march 由 ISA 决定，
build_preload_so 会用 sve2 march 编译；候选是纯 NEON 内联，SVE2 下
同样可用）。950 的额外 SVE2 赢点（dct8 +48%、ivpp16 +47% 等）可
按 docs/35 与 kernels 现有候选补充注入。
