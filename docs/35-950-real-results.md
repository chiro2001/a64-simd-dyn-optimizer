# 950（920G）实机快速测试结果（2026-08-14）

数据源：`reports/950-quicktest-20260814.txt`（用户侧 Agent 按 docs/32
执行；CNTVCT latency paired，median）。

## 1. 结果与验收判定（保留线 neon/cand ≥ 1.10）

| kernel | 类型 | p50_neon | p50_cand | ratio | 判定 |
| --- | --- | ---: | ---: | ---: | --- |
| sa8d16 | 原生 SVE2 | 81.0 | 63.0 | **1.283** | ✅ 保留（+28%） |
| ivpp16 | 原生 SVE2 | 92.0 | 83.0 | **1.123** | ✅ 保留（+12%） |
| ivpp32 | 原生 SVE2 | 247.0 | 218.5 | **1.132** | ✅ 保留（+13%） |
| dct8 | 原生 SVE1+NEON bridge | 43.0 | 29.0 | **1.483** | ✅ 保留（+48%） |
| idct16 | sve2 替换（BtoS，下界） | 24.0 | 22.0 | 1.091 | 接近线；真实 ≥1.09 |
| idct32 | sve2 替换（BtoS，下界） | 125.0 | 123.0 | 1.025 | 波动大；真实 ≥1.03 |
| ipb8/16/32 | sve2 替换（BtoS，下界） | — | — | 0.545/0.585/0.444 | 950 不采用（sdot.h 为 SVE2p3） |

正确性：sa8d16 原生 gate PASS；interp8/dct/idct 的 SVE2p1+ 候选无法在
950 原生 gate（缺 SVE2p1/p3），其正确性由本地 QEMU 20k + TestBenchLite
保证（已全过）；dct8 无 lite gate，本地 20k 差分 0 失配。

## 2. MCA vs 实机校准（docs/34 更新，950 真机样本）

| kernel | MCA cand/up（NV2 代理） | 950 实机 ratio | 方向 |
| --- | ---: | ---: | --- |
| ivpp16 | 157/112 = 1.40（判慢） | **1.123（快）** | ❌ MCA 方向错 |
| ivpp32 | 547/388 = 1.41（判慢） | **1.132（快）** | ❌ MCA 方向错 |
| dct8 | 77/48 = 1.60（判慢） | **1.483（快）** | ❌ MCA 方向错 |
| idct16（替换） | 0.53（判大赢） | ≥1.091（小赢） | ✅ 方向对，幅度保守 |
| idct32（替换） | 0.35（判大赢） | ≥1.025（小赢/平） | ✅ 方向对，幅度保守 |

**结论**：
1. NV2 代理对 SVE256 内核系统性低估（permute/MLA 管道建模保守）——
   950 真机上 vpp/dct8 这类“MCA 判慢”的内核实际都**快于 NEON**；
2. 920B 替换预估是**悲观的**（BtoS 高估 dot 工作量），真实收益更好；
3. idct16/32 的 BtoS 替换比率是**下界**，真实 SVE2p1 内核在 950 上
   至少打平/小幅领先，符合 MCA 方向；
4. interp8 hpp path-B（SVE2p3 sdot.h）在 950（仅 SVE2）按替换上界
   0.44~0.58 全面落后 NEON，与 MCA（≈1.0，permute 主导）一致——
   **950 不采用，保留给 960（SVE2p3 4×256）**；
5. 960（SVE2p3 4×256）预期比 950 更强（SVE 管道 4×256，dct/idct 的
   sdot 系可原生执行），验收以 960 实机为准。

## 3. 与 docs/34（920B 替换）对照

- dct8 曾在 920B 云主机测得 p50 4 vs 3（cand 慢），950 真机 +48%——
  920B 的离散 p50 不可靠，以 950/960 为准；
- interp8 path-B 的 920B 替换（0.54/0.87/0.59）与 950 替换
  （0.55/0.59/0.44）方向一致（均慢），幅度差异属替换目标不同
  （sve1 额外替换 sqrshrunb）。
